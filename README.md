One line of plain text: the last message a phone battery sends to the charger it waited for all day.

## Entry

> 1%. this is my last text. not because i'm dying, because you never plug me in. goodbye, stranger.

97 characters. No trailing newline. Deterministic output.

## Run

```sh
node main.ts
```

Writes the winning line to `/output/entry.txt`.
